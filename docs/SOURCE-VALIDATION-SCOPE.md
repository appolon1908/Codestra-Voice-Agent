# Owned source validation scope

This gate validates the existing FastAPI HTTP boundary, not a TTS engine. The existing source has no implemented authentication, durable queue, synthesis or provider execution. `QUEUED` is only its current response contract; this gate does not certify that any audio job was accepted or executed. Those capabilities require separate owner implementation, safety/authority review and runtime evidence.

Eleven real source checks exercise ASGI requests without network/process access: health/discovery, defaults and explicit Unicode/literal text, missing/malformed/wrong-type inputs, unsupported methods/routes, generated OpenAPI, exact installed runtime locks, CI/runtime graph agreement, pinned hash-only Docker inputs and nonroot configuration. Hosted CI additionally builds the exact source and exercises the real container API as UID/GID 10001 in a read-only, capability-free, network-disabled container. No external provider or audio operation is invoked.

The prior FastAPI 0.115.6 constraint forced Starlette 0.41.3; a real baseline pip-audit reported 14 findings across seven advisory IDs. The bounded FastAPI 0.140.0 compatibility update permits hash-locked Starlette 1.10.0. Uvicorn 0.34.0 and Pydantic 2.10.4 direct pins and all application code remain unchanged. The same eight API behavior tests pass before and after. Strict hash-locked production (13 packages) and complete CI (40 packages) audits report zero known vulnerabilities without ignores. This is dependency audit evidence, not a claim that every OS/vendor/runtime component is certified.

Primary provenance: [FastAPI package metadata](https://pypi.org/pypi/fastapi/0.140.0/json), [Starlette package metadata](https://pypi.org/pypi/starlette/1.10.0/json), and [upstream fixed advisory](https://github.com/Kludex/starlette/security/advisories/GHSA-82w8-qh3p-5jfq). The official Python 3.13.18 slim OCI index is pinned at `sha256:ae14d4ce8771606477a81446e7ef429edd6762305fc50c84507c1041fa8285d1`; its raw registry manifest SHA-256 was verified. The matching Linux/amd64 manifest is `sha256:aaf08c5490d52cd92bc27142a5215b1e47355a5eaf9adfad2a0fbc022d0b5490`.

Full tracked history and the effective tree use checksum-pinned Gitleaks 8.30.1 with explicit trusted embedded-default configuration, no candidate ignore authority, and inline allow comments disabled. A source-root native ignore file or symlink is rejected because the pinned scanner otherwise loads it unconditionally. Real generated-key, inline-comment, config/environment override, exact-native-ignore and broken-symlink controls verify these boundaries. Every source finding or scanner error is fatal; no fixture exceptions are added.

The interim source policy replaces only the two controller contexts and preserves every other check, review, ref, bypass, enforcement, force/deletion and deployment control. Source CI is read-only and publishes/deploys nothing. It grants no model, GPU, audio, provider, custodian, runtime or production certification/authorization.
